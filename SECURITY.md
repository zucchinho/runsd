# Security policy

## Supported versions

Only the [latest release](https://github.com/zucchinho/runsd/releases/latest)
receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/zucchinho/runsd/security/advisories/new).

Include what you found, the version affected and steps to reproduce it.

## Verifying releases

Each release publishes a `checksums.txt` and a build provenance attestation.
See [Verifying a release](README.md#verifying-a-release).
